# admin-auth — 后台登录鉴权

## Purpose

为后台管理端提供账号登录与接口鉴权能力，保证管理类接口（建单、订单管理、看板）仅对持有有效会话凭证的运营人员开放，并将操作归属到具体登录账号。

## ADDED Requirements

### Requirement: 账号密码登录
系统 SHALL 提供账号密码登录：凭据正确时签发访问令牌并返回账号信息；凭据错误时拒绝登录并返回明确错误提示，不泄露账号是否存在。

#### Scenario: 正确凭据登录成功
- **WHEN** 使用正确的账号与密码请求登录
- **THEN** 系统返回有效的访问令牌与账号信息（含账号名），后续请求可携带该令牌访问管理接口

#### Scenario: 错误密码登录失败
- **WHEN** 使用存在但密码错误的账号请求登录
- **THEN** 系统拒绝登录并返回统一的"账号或密码错误"类提示，不签发令牌

### Requirement: 管理接口鉴权
系统 SHALL 对所有管理类接口强制鉴权：未携带令牌、令牌无效或已过期的请求 SHALL 被拒绝（未授权响应），且不执行任何业务操作。

#### Scenario: 无令牌访问管理接口
- **WHEN** 请求未携带访问令牌调用管理类接口（如创建订单）
- **THEN** 系统返回未授权错误，不执行业务操作

#### Scenario: 携带有效令牌访问成功
- **WHEN** 请求携带有效且未过期的访问令牌调用管理类接口
- **THEN** 系统正常执行业务操作

#### Scenario: 令牌过期被拒绝
- **WHEN** 请求携带已过期的访问令牌调用管理类接口
- **THEN** 系统返回未授权错误，客户端需重新登录

### Requirement: 操作归属记录
系统 SHALL 将后台创建的关键业务数据（补差价单等）关联到执行操作的登录账号，供查询与对账时追溯操作人。

#### Scenario: 建单记录操作人
- **WHEN** 已登录账号创建一笔补差价单
- **THEN** 订单记录关联该账号，订单详情中可查到创建人
